Recodificación de variables

# Reordeno variables para simplificar el análisis.
datos_modelo <- datos_modelo |> 
  mutate(
    # Agrupo el estado civil en dos categorías principales.
    ## La categoría "married" reúne a personas casadas; el resto queda agrupado como "not_married".
    marital_simple = case_when(
      str_detect(marital_status, "Married") ~ "married",
      TRUE ~ "not_married"
    ),
    
    # Agrupo el país de origen en dos categorías.
    ## Esto permite distinguir entre personas nacidas en Estados Unidos y personas nacidas en otros países.
    native_country_simple = case_when(
      native_country == "United-States" ~ "United States",
      TRUE ~ "Other"
    ),
    
    # Transformo ganancias y pérdidas de capital con log1p.
    ## Uso log1p(x) porque equivale a log(x + 1), lo que evita problemas cuando el valor original es 0.
    log_capital_gain = log1p(capital_gain),
    log_capital_loss = log1p(capital_loss)
  ) |> 
  
  # Defino explícitamente las categorías de referencia de algunas variables.
  ## Estas referencias sirven como punto de comparación en la regresión logística.
  mutate(
    sex = factor(sex),
    marital_simple = factor(marital_simple, levels = c("not_married", "married")),
    native_country_simple = factor(native_country_simple, levels = c("United States", "Other")),
    race = factor(race),
    occupation = factor(occupation),
    education = factor(education)
  )

Decisión sobre la interacción

Nota

A partir del análisis exploratorio, resulta razonable incorporar una interacción entre education_num y sex. La educación suele estar asociada con mejores oportunidades laborales y mayores ingresos, pero ese efecto puede no ser igual para varones y mujeres. En términos sustantivos, la interacción permite evaluar si el aumento en la probabilidad de tener ingresos superiores a 50.000 dólares asociado a mayores años de educación cambia según el sexo de la persona.

Por ese motivo, el primer modelo se estimará sin interacciones y el segundo incorporará el término education_num * sex. De esta manera, el modelo interactivo no solo observará el efecto general de la educación, sino también si ese efecto varía entre grupos.

Ajuste de modelos de regresión logística

Nota

En esta sección se estiman dos modelos de regresión logística binomial. El primer modelo funciona como modelo base y no incluye interacciones. El segundo modelo incorpora la interacción entre education_num y sex, justificada en la sección anterior.

# Ajusto el Modelo 1, sin interacciones.
## La variable dependiente es income, con <=50K como categoría de referencia y >50K como categoría cuya probabilidad se busca modelar.
modelo_1 <- glm(
  income ~ age +
    education_num +
    sex +
    marital_simple +
    race +
    hours_per_week +
    log_capital_gain +
    log_capital_loss +
    native_country_simple,
  data = datos_modelo,
  family = binomial
)

# Ajusto el Modelo 2, incorporando la interacción entre educación y sexo.
## La interacción permite evaluar si el efecto de los años de educación sobre la probabilidad de tener ingresos altos cambia según el sexo.
modelo_2 <- glm(
  income ~ age +
    education_num * sex +
    marital_simple +
    race +
    hours_per_week +
    log_capital_gain +
    log_capital_loss +
    native_country_simple,
  data = datos_modelo,
  family = binomial
)

## Decisión sobre la interacción

::: callout-note
A partir del análisis exploratorio, resulta razonable incorporar una interacción entre `education_num` y `sex`. La educación suele estar asociada con mejores oportunidades laborales y mayores ingresos, pero ese efecto puede no ser igual para varones y mujeres. En términos sustantivos, **la interacción permite evaluar si el aumento en la probabilidad de tener ingresos superiores a 50.000 dólares asociado a mayores años de educación cambia según el sexo de la persona.**

Por ese motivo, el primer modelo se estimará sin interacciones y el segundo incorporará el término **`education_num * sex`**. De esta manera, el modelo interactivo no solo observará el efecto general de la educación, sino también si ese efecto varía entre grupos.
:::

# Ajuste de modelos de regresión logística

::: callout-note
En esta sección se estiman **dos modelos de regresión logística** binomial. El primer modelo funciona como modelo base y no incluye interacciones. El segundo modelo incorpora la interacción entre **`education_num` y `sex`**, justificada en la sección anterior.
:::

```{r}
#| label: modelos-logisticos
#| warning: false
#| message: false

# Ajusto el Modelo 1, sin interacciones.
## La variable dependiente es income, con <=50K como categoría de referencia y >50K como categoría cuya probabilidad se busca modelar.
modelo_1 <- glm(

)

modelo_2 <- glm(
  income ~ age +
    education_num * sex +
    marital_simple +
    race +
    hours_per_week +
    log_capital_gain +
    log_capital_loss +
    native_country_simple,
  data = datos_modelo,
  family = binomial
)

summary(modelo_2)
```

El **Modelo 1** estima la asociación entre cada predictor y la probabilidad de tener ingresos superiores a 50.000 dólares, manteniendo constantes las demás variables del modelo. El **Modelo 2** conserva los mismos predictores, pero agrega la interacción entre `education_num` y `sex`. Por lo tanto, permite observar si la relación entre educación e ingresos altos varía según el sexo de la persona.
:::

# Comparación global de modelos

::: callout-note
En esta sección **se comparan el Modelo 1 y el Modelo 2** para evaluar si la inclusión de la interacción entre `education_num` y `sex` mejora el ajuste general. Para eso se utilizan **dos criterios:** el `AIC` y el `Pseudo R²` calculado a partir de las deviances.
:::

```{r}
#| label: comparacion-modelos
#| warning: false
#| message: false

# Comparo ambos modelos usando métricas globales de ajuste.
## broom::glance() permite extraer indicadores generales del modelo, como AIC, deviance y null.deviance.
comparacion_modelos <- bind_rows(
  glance(modelo_1) |> 
    mutate(modelo = "Modelo 1: base"),
  
  glance(modelo_2) |> 
    mutate(modelo = "Modelo 2: interacción")
) |> 
  mutate(

# Calculo el Pseudo R² visto en clase a partir de las deviances.
    pseudo_r2 = 1 - deviance / null.deviance
  ) |> 
  select(
    modelo,
    AIC,
    BIC,
    deviance,
    null.deviance,
    pseudo_r2
  )

# Presento la comparación en una tabla estética.
comparacion_modelos |> 
  mutate(
    AIC = round(AIC, 2),
    BIC = round(BIC, 2),
    deviance = round(deviance, 2),
    null.deviance = round(null.deviance, 2),
    pseudo_r2 = round(pseudo_r2, 4)
  ) |> 
  kable(
    col.names = c(
```
